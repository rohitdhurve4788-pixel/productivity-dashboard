## 🔥 Features

### ✅ Todo List

* Add tasks
* Mark important tasks 🚨
* Delete tasks
* Data saved using **localStorage**

---

### ✅ Daily Planner

* Hourly planning system (6 AM – 12 AM)
* Auto-save input using **localStorage**

---

### ✅ Pomodoro Timer

* 30 min work session
* 10 min break session
* Start / Pause / Reset functionality

---

### ✅ Motivational Quotes

* Fetch random quotes from API
* Display quote + author dynamically

---

### ✅ Weather Info

* Fetch real-time weather using API
* Shows:

  * Temperature in celcius 🌡️
  * Feels like
  * Humidity 💧
  * Wind speed 🌬️

---

### ✅ Daily Goals Tracker

* Add daily goals
* Mark as completed
* Delete goals
* Stored in **localStorage**

---
